## Graceful Degradation and Service Workers

Graceful degradation and service workers connect because service workers help a website still work even if the internet connection is weak or completely gone. Instead of the whole app breaking, important files like the HTML, CSS, JavaScript, and saved recipe information can be loaded from cache. This means the app may not have every feature available, but users are still able to use the main parts of the website instead of seeing an error page.
